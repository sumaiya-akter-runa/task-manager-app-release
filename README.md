## About

Task Manager App is a mobile application developed with Flutter as part of a live class assignment. This repository hosts the compiled Android release (APK) so the app can be downloaded and installed directly on a device.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Simple and easy-to-use interface

## Installation

1. Open the [Releases](https://github.com/sumaiya-akter-runa/task-manager-app-release/releases) page.
2. Under **Assets**, download `app-release.apk` from the latest release.
3. Open the downloaded APK on your Android phone.
4. If prompted, allow installation from this source.
5. Tap **Install**, then launch the app.

## Requirements

- Android phone (Android 5.0 or higher recommended)
- Permission to install apps from unknown sources (only for the first install)

## Troubleshooting

**Installation blocked?**
Go to *Settings > Security (or Apps) > Install unknown apps*, then allow your browser or file manager to install apps.

**"App not installed" message?**
Uninstall any older version of the app and try again.
